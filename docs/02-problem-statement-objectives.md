# Problem Statement and Objectives

## Problem Statement

Students and beginner investors often need practical exposure to stock-market behavior, but real trading involves financial risk. Static learning materials explain concepts, but they do not provide hands-on experience with order placement, portfolio tracking, or changing market prices.

Trade Abhyas addresses this problem by providing a virtual stock trading platform where users can practice with simulated funds and realistic order behavior while learning safely.

## Primary Objectives

1. Provide a safe paper-trading environment using virtual capital.
2. Support realistic NSE equity instrument search and selection.
3. Allow users to place Market, Limit, Stop-Loss, and Stop-Limit orders.
4. Maintain accurate user balance, holdings, transactions, and order history.
5. Calculate weighted average price, realized P&L, and unrealized P&L.
6. Enforce trading rules such as oversell prevention and insufficient balance rejection.
7. Handle order execution safely under concurrent requests.
8. Provide secure user authentication and role-based admin authorization.

## Secondary Objectives

1. Provide live/current market quote visibility.
2. Display historical stock charts.
3. Provide watchlists and price alerts.
4. Provide leaderboard and competition modules for learning engagement.
5. Provide an admin application for monitoring users, orders, transactions, and competitions.
6. Provide real-time updates using Socket.IO.
7. Prepare production environment configuration without exposing secrets.
8. Maintain financial integrity through automated tests and audit scripts.
