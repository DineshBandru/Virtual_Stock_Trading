# Limitations and Future Scope

## Current Limitations

| Limitation | Explanation |
| --- | --- |
| Virtual trading only | Trades are simulated and do not reach a real exchange or brokerage account. |
| No real settlement | There is no real cash movement, demat settlement, or bank integration. |
| Market data dependency | Quote availability depends on external market-data responses. |
| Educational accuracy | The system models important trading concepts but does not fully reproduce all exchange-level microstructure. |
| Limited asset class scope | The current focus is NSE equity-style instruments. |
| Visual validation boundary | Final academic screenshots may still need to be captured and arranged for the submitted report. |

## Explicitly Out of Scope

Trade Abhyas does not include:

- Bank account verification.
- PAN card collection.
- UPI or payment collection.
- Brokerage login.
- Demat account integration.
- Real order routing.
- Real investment advice.
- Compliance-grade KYC.

## Future Scope

Potential improvements include:

- More detailed charting and technical indicators.
- Competition seasons with richer scoring rules.
- Practice lessons and guided trading challenges.
- Admin-configurable virtual capital policies.
- More advanced risk analytics.
- Exportable user performance reports.
- Better mobile visual polish and project-ready screenshots.
- Expanded alert types such as percentage movement or portfolio-level alerts.
- Optional paper-trading tutorials for beginners.

## Production Readiness Improvements

Before a public production launch, the project should include:

- Final production environment variables.
- Verified production email provider setup.
- Formal backup and monitoring plan.
- Error tracking and logging dashboard.
- Production domain and HTTPS verification.
- Final browser screenshots across desktop and mobile.
